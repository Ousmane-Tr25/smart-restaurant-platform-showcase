# Security and privacy of this public showcase

This repository is intentionally limited to static presentation files and anonymized product visuals.

It must never contain:

- `.env` files or database connection strings;
- API keys, provider secrets or webhook secrets;
- SMTP passwords, VAPID private keys or encryption keys;
- customer names, phone numbers, email addresses, addresses or order tokens;
- database files, SQL dumps, Neon backups or production logs;
- the complete commercial application source code.

The product itself includes server-side payment verification, idempotent webhook processing, CSRF/origin protections, hardened security headers, encrypted Web Push subscription material, customer privacy workflows and encrypted backup support.

Security reports concerning this public repository can be submitted through the author's GitHub profile.
